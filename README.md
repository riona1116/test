# KrishiConnect Enhanced Website

## Overview
KrishiConnect is a comprehensive agricultural marketplace platform that connects farmers directly with wholesalers and buyers. This enhanced version features improved UI/UX, functional authentication, profile management, and a complete product catalog.

## Features Implemented

### 🎨 Enhanced UI/UX
- Modern, responsive design with improved color scheme
- Smooth animations and transitions
- Professional typography and layout
- Mobile-friendly responsive design
- Attractive slideshow with navigation dots
- Clean, intuitive navigation

### 🔐 Authentication System
- Dual user types: Farmer and Wholesaler
- Phone number + access code authentication
- Demo credentials provided for testing
- Session management with user-specific dashboards

### 👨‍🌾 Farmer Dashboard
- Personal dashboard with statistics
- Crop management (add, edit, view)
- Profile management with picture upload
- Market price monitoring
- Recent activity tracking
- Earnings and inquiry tracking

### 🏪 Wholesaler Dashboard
- Browse available crops from farmers
- Contact farmers directly
- Market price analysis
- Profile management
- Search and filter functionality

### 📱 Core Pages
- **Homepage**: Slideshow, featured products, about section
- **Product Listing**: 16 products with real vegetable images
- **Market Prices**: Live pricing with filters and trends
- **User Dashboards**: Role-specific interfaces
- **Profile Management**: Picture upload and information editing

### 🖼️ Visual Assets
- Logo integration on all pages
- 13 high-quality vegetable images
- Professional slideshow images
- Consistent branding throughout

## Usage Instructions

1. **Start with Homepage**: Open `index.html` to see the enhanced homepage with slideshow
2. **Browse Products**: Click "Products" to see the 16-item catalog with real images
3. **Check Prices**: Visit "Market Prices" for live pricing information
4. **Login as Farmer**: Use demo credentials to access farmer dashboard
5. **Login as Wholesaler**: Use demo credentials to access wholesaler interface
6. **Test Features**: Try adding crops, updating profile, uploading pictures
